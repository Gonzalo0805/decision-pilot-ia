# Decision Pilot IA

## Objetivo

Aplicación web para estructurar decisiones complejas utilizando IA.

## Problema que resuelve

Evita decisiones automáticas y obliga a analizar contexto, datos, riesgos y alternativas.

## Casos incluidos

* Admisión universitaria
* Soporte TI
* E-commerce
* Documentación interna

## Uso

1. Seleccionar un caso
2. Revisar o editar los datos
3. Generar prompt
4. Copiar y usar en IA

## Estructura

* index.html → interfaz
* style.css → diseño
* app.js → lógica
* prompts.js → generación de prompts
* data/ejemplos.json → casos

## Despliegue

Publicado con GitHub Pages

## Limitaciones

* No toma decisiones automáticamente
* Depende de la calidad del prompt
